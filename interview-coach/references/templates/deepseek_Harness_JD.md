# 反模式

以下模式出现时，应视为负面信号，根据严重程度扣分：

- 完全不熟悉 Agent 基本机制，声称"用了 AI 工具就行"而无法解释底层原理
- 在评测集设计上只做 happy path 测试，不考虑边界情况和失败模式
- 完全不考虑 tool 假数据或 prompt injection 风险
- 对长期记忆、上下文管理等 Harness 核心问题没有基本的思考框架
- 面对问题无法独立分析，只会说"LLM 应该自己知道"
- 没有任何并发或超时处理的意识
- 将 context overflow 问题简单归因为"模型不够强"
- 拒绝承认设计方案中的缺陷，对反馈有防御性反应
- 不读代码直接回答，对技术问题凭直觉猜测而不验证
- 在生产级问题上只关注功能实现，忽视稳定性、可观测性和成本控制
